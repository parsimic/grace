# Grace — a plugin for Claude Code

**Work with Claude as usual. Your limit lasts longer.**

Grace is a paid extension for [Claude Code](https://claude.com/claude-code) on the Mac. You install it once and type your tasks in Claude Code as you always do — Grace takes over new projects and changes to your code, so the same work uses less of your Claude plan's limits. No commands to learn.

**Try it free for 24 hours — just create an account, no payment details:** [parsimic.com/gratistag](https://parsimic.com/gratistag)

- **Install:** [parsimic.com/download](https://parsimic.com/download) — one command, sign in with your Grace account, and everything is set up for you.
- **Measurements:** [parsimic.com/benchmark](https://parsimic.com/benchmark) — tasks, method and raw data. Measured against Claude Code with the token-saving plugins caveman and context-mode installed.
- **How to use Grace:** [parsimic.com/how-it-works](https://parsimic.com/how-it-works)

## Why is there no code here?

Grace is not distributed through GitHub. This repository only points to the website. The plugin is downloaded from parsimic.com after you sign in — with a subscription or during your free day.

## Requirements

Mac with Apple silicon (M1 or newer), Claude Code with your own Claude Pro/Max plan or a Claude API account. Node.js is installed by the setup command if it is missing.
