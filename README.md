# Grace — a plugin for Claude Code

**Work with Claude as usual. Your limit lasts longer.**

Grace is a paid extension for [Claude Code](https://claude.com/claude-code) on the Mac. You install it once and type your tasks in Claude Code as you always do — Grace takes over new projects and changes to your code, so the same work uses less of your Claude plan's limits. No commands to learn.
