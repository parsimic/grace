# Grace — a plugin for Claude Code

**Claude writes less. Your limit lasts longer.**

Grace is a paid extension for [Claude Code](https://claude.com/claude-code) on the Mac. Claude plans and writes the hard parts; Grace writes the easy parts locally with an open model on your Mac, runs the tests, and hands back what it cannot do.

- **Install:** [parsimic.com/download](https://parsimic.com/download) — one command, sign in with your Grace account, and everything is set up for you.
- **Measurements:** [parsimic.com/benchmark](https://parsimic.com/benchmark) — tasks, method, raw data.
- **How it works:** [parsimic.com/how-it-works](https://parsimic.com/how-it-works)

## Why is there no code here?

Grace is not distributed through GitHub. This repository only points to the website. The plugin is downloaded from parsimic.com after you sign in with an active subscription.

## Requirements

Mac with Apple silicon, 32 GB memory recommended, Claude Code with a Claude Pro/Max plan or a Claude API account. Node and the local model are installed by the setup command if they are missing.
